Glosario Técnico de Redes y Computación

36 conceptos esenciales de redes, hardware y mantenimiento, con buscador, filtros por tema y modo tarjetas para repasar.

Redes

Throughput

Cantidad real de datos que se transfieren con éxito por unidad de tiempo, normalmente en Mbps o Gbps.

Ej.: un enlace de 100 Mbps con 70 Mbps reales tiene un throughput de 70 Mbps.

Redes

Bandwidth (Ancho de banda)

Capacidad máxima teórica de datos que puede llevar una conexión en un tiempo dado.

Ej.: un plan de 200 Mbps tiene ese ancho de banda como tope, no como velocidad garantizada.

Redes

NIC (Tarjeta de red)

Componente que conecta un equipo a una red, por cable o Wi-Fi, y tiene una dirección MAC única.

Ej.: la NIC es lo que permite que tu PC se conecte al router.

Redes

Packet (Paquete)

Bloque de datos que viaja por la red con origen, destino y parte del mensaje completo.

Ej.: un video se divide en muchos paquetes que se reordenan al llegar.

Redes

Latencia

Tiempo que tarda un dato en ir de un punto a otro de la red; se mide en milisegundos (ms).

Ej.: en juegos, una latencia alta se nota como retraso al responder.

Redes

Dirección IP

Número único que identifica a un dispositivo dentro de una red, como 192.168.1.10.

Ej.: el router asigna una IP a cada equipo conectado en casa.

Redes

DNS

Sistema que traduce nombres de dominio, como nvision.social, a direcciones IP.

Ej.: sin DNS tendrías que escribir la IP del sitio en vez de su nombre.

Redes

DHCP

Protocolo que asigna automáticamente direcciones IP y otros datos de red a los dispositivos.

Ej.: al conectarte al Wi-Fi, el router te da una IP por DHCP.

Redes

Router

Dispositivo que conecta redes distintas y dirige el tráfico entre tu red local e internet.

Ej.: el router de una casa conecta su red local con internet.

Redes

Switch

Dispositivo que conecta varios equipos dentro de una misma red local y les pasa los datos.

Ej.: un switch conecta por cable varias PCs de un salón.

Redes

Modelo OSI

Modelo de 7 capas (física, enlace, red, transporte, sesión, presentación, aplicación) para entender cómo se comunica una red.

Ej.: el cable es capa física; una IP es capa de red.

Redes

TCP

Protocolo que envía los datos de forma ordenada y verifica que lleguen completos.

Ej.: cargar una página web usa TCP porque no puede faltar nada.

Redes

UDP

Protocolo rápido que envía datos sin confirmar cada entrega; si algo se pierde, no se reenvía.

Ej.: las videollamadas y los juegos usan UDP por su baja latencia.

Redes

Wi-Fi 6

Versión de Wi-Fi más rápida y eficiente con muchos dispositivos a la vez, gracias a OFDMA y MU-MIMO.

Ej.: muchos routers actuales ya traen Wi-Fi 6.

Redes

LAN

Red de área local: los equipos conectados dentro de una casa, oficina o salón.

Ej.: tu PC, tu celular y tu TV forman una LAN en casa.

Redes

WAN

Red de área amplia que conecta redes lejanas, como internet.

Ej.: tu LAN se conecta a la WAN a través del router.

Redes

Firewall (Cortafuegos)

Sistema que filtra el tráfico de red y bloquea accesos no permitidos.

Ej.: el firewall de Windows bloquea conexiones sospechosas.

Redes

Dirección MAC

Identificador físico único de cada tarjeta de red, formado por 6 pares de caracteres hexadecimales.

Ej.: viene impresa en la etiqueta del router.

Redes

Puerta de enlace (Gateway)

Punto de salida de una red local hacia otra red, normalmente la IP del router.

Ej.: en casa, la puerta de enlace suele ser 192.168.0.1.

Redes

Máscara de subred

Número que separa la parte de red y la parte de host de una dirección IP, como 255.255.255.0.

Ej.: con /24, una red tiene hasta 254 equipos.

Hardware

CPU (Procesador)

El cerebro del equipo: ejecuta las instrucciones de los programas.

Ej.: un CPU más rápido abre programas y responde antes.

Hardware

GPU (Tarjeta gráfica)

Procesa gráficos e imágenes y acelera tareas como juegos, video y diseño.

Ej.: una GPU dedicada rinde mejor en juegos que la integrada.

Hardware

RAM (Memoria)

Memoria temporal y rápida donde trabajan los programas abiertos; se vacía al apagar.

Ej.: con poca RAM, el PC se pone lento con varias apps abiertas.

Hardware

SSD

Almacenamiento rápido sin partes móviles, basado en memoria flash.

Ej.: Windows arranca en segundos desde un SSD.

Hardware

HDD

Disco duro mecánico con platos giratorios; más barato por GB, pero más lento que un SSD.

Ej.: un HDD sirve para guardar muchos archivos que no se usan a diario.

Hardware

NVMe

Tipo de SSD muy rápido que se conecta por PCIe y supera por mucho a un SSD SATA.

Ej.: un NVMe es ideal para el disco donde está Windows.

Hardware

Placa base (Motherboard)

Tarjeta principal que conecta CPU, RAM, almacenamiento y demás componentes.

Ej.: la placa base define qué CPU y cuánta RAM soporta el equipo.

Hardware

BIOS / UEFI

Programa inicial que arranca el equipo y verifica el hardware antes de cargar el sistema.

Ej.: desde UEFI se cambia el orden de arranque del PC.

Hardware

Fuente de poder (PSU)

Convierte la corriente de la pared en energía segura para los componentes del PC.

Ej.: una fuente débil puede apagar el PC al jugar.

Hardware

Pasta térmica

Compuesto que mejora el contacto entre el CPU y su disipador para transmitir el calor.

Ej.: se cambia cuando el CPU se calienta más de lo normal.

Hardware

Caché

Memoria muy rápida y pequeña que guarda datos que el CPU usa con frecuencia.

Ej.: la caché evita que el CPU espere tanto a la RAM.

Mantenimiento

Sistema operativo

Software base que gestiona el hardware y permite usar programas, como Windows o Linux.

Ej.: Windows 11 es el sistema operativo de muchos PCs.

Mantenimiento

Antivirus

Programa que detecta, bloquea y elimina software malicioso.

Ej.: Windows Defender es el antivirus incluido en Windows.

Mantenimiento

Copia de seguridad (Backup)

Copia de tus archivos en otro lugar para recuperarlos si el equipo falla o se pierde.

Ej.: guarda tus trabajos en un disco externo o en la nube.

Mantenimiento

Controlador (Driver)

Programa que permite que el sistema operativo use un componente, como la tarjeta gráfica o el Wi-Fi.

Ej.: sin el driver de Wi-Fi, el PC no ve las redes.

Mantenimiento

Malware

Software malicioso diseñado para dañar, robar datos o controlar un equipo sin permiso.

Ej.: un virus y un troyano son tipos de malware.

Toca la tarjeta para ver la definición. «Mezclar» cambia el orden para repasar.

Código

Tu IP y tu MAC

Muestra la dirección IP de tu equipo y la dirección física (MAC) de tu tarjeta de red: los dos datos que te identifican en la red.

powershell
ipconfig /all
Código

¿Hay conexión? Haz ping

Envía paquetes al servidor de Google (8.8.8.8). Si responde, tu conexión funciona; si todo se pierde, el problema está en tu red local.

powershell
ping 8.8.8.8
Código

¿Quién está en tu red?

Lista los dispositivos de tu red local con su IP y su MAC: los equipos que el tuyo ya conoce.

powershell
arp -a
Código

Renueva tu IP

Suelta tu IP actual y pide una nueva al router. Es el arreglo clásico cuando el internet se pone raro (ejecuta PowerShell como administrador).

powershell
ipconfig /release ipconfig /renew
